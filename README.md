# JARVIS - Dein persönlicher KI-Assistent
Design: Schwarz + Dunkles Weinrot, Orb ohne Mikro-Symbol
Kostenlos. Lokal. Stück für Stück aufgebaut.

## Setup (Windows / MacBook)
1. Python 3.11+ installieren (Haken bei Add to PATH)
2. In diesem Ordner Terminal öffnen:
   pip install -r requirements.txt
3. Server starten:
   python app.py
4. Auf dem iPad: Safari -> http://DEINE-LAPTOP-IP:5000
   Teilen -> Zum Home-Bildschirm

## Was kann er?
- Sprechen (Mikrofon -> Antwort -> Stimme)
- Wishlist, News (Tagesschau), Termine (Demo)
- Design: Schwarz / Dunkles Weinrot
